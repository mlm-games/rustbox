# 3D Models

Active in-game visuals are the **Rbox smooth pack** (`rbox/`, CC0
derivatives, Blender-beveled + shade-smooth so edges read rounded instead of
voxel). Collision/hitboxes are unchanged (engine `BuiltinShape` math).

| Source | License | Used for |
| ------ | ------- | -------- |
| Kenney Platformer Kit 4.1 (`kenney.nl/assets/platformer-kit`) | CC0 1.0 Universal | Smooth style source vendored to `pack/` (Blox, Crate, Spring, Key, Heart, Jewel, Star, Flag, Sign, Lever, Door, Pipe, Barrel, Bomb, Plate, Ramp, Conveyor, Ladder, Player, colormap atlas) |
| Quaternius Cube World Kit (`quaternius.com/packs/cubeworldkit.html`, local `~/Downloads/Cube World - Aug 2023` Blends/glTF) | CC0 1.0 Universal | Proportion/bbox reference only for kitbash scale + `cubeworld/` fallback and animation-clip source (`Character_Male_2` player Idle/Run/Jump, `Goblin` Prowler Idle/Walk) |
| `rbox/blocks/*.glb` (170) | CC0 derivative (generated `tools/asset_build/build_rbox.py`) | All block kind×shape pairs, smoothed from `rustbox/` geometry |
| `rbox/entities/*.glb` (22 + Player) | CC0 derivative (generated `tools/asset_build/build_rbox.py`) | Kenney direct copies (Crate, Key, Sign, Heart, Jewel, Spring, Flag, Star, Lever, Ramp, Plate, Bomb, Barrel) + smooth kitbashes (Seal, LockGate, RelayGate, Prowler, Fan, Teleporter) normalized to the voxel bbox |
| `rustbox/blocks/*.glb`, `rustbox/entities/*.glb` | CC0 derivative | Legacy voxel kit, kept as build reference (not runtime) |
| `cubeworld/Character_Male_2.gltf`, `cubeworld/Goblin.gltf` | CC0 | Player/prowler rigs + clip library (retarget to Kenney `Player.glb` idle/walk/jump is a follow-up.|

Models are self-contained glTF 2.0 (embedded buffers).

## Runtime wiring

`assets/models/{blocks,entities}.ron` (generated by
`tools/asset_build/gen_rbox_manifests.py`) map every kind/shape to
`models/rbox/...`; `src/maker/{block_asset_manifest,asset_manifest}.rs`
defaults match so a missing RON still resolves to Rbox.
